## 8. 容器

> 容器就是**可存多个数据**的东西。

### 容器有 `list`、`str`、`tuple`、`set`、`dict`。

### 8.1 list 列表
- **list 是有序、可重复、可修改**的，可存不同数据类型。

- 索引：从前往后 `0~N`，从后往前 `-1~-N`。

  ```
  a=[2,3,4,5,5,6]
  a[0]=4 #修改a中的2为4
  del a[1] #删除a中的3
  
  切片左闭右开
  c=a [,2] #c值:[2,3] 
  c=a [1,5,2] #c值:[3,5] 
  ```

- **修改**：直接指定那个下标赋值即可。

- **删除**：`del` 后面跟指定那个下标。

- **切片**：截取的列表，是列表名后面跟 `[ ]`、 **star和end中间用 `:`隔开**。
  前面是开始的数，后面是结束的数，再后面是步数，
  **左闭右开**。可正反向调用。

- 常见方法：
  - `append()`：自动添加到最后面。
  - `insert(位置, 数)`：在指定位置插入。
  - `remove(值)`：按**值**删除。
  - `pop()`：按**索引**删除，默认删最后一个（索引 -1），也可以替代 `remove`。
  - `sort()`：排序，条件是里面数据类型必须相同。
  - `reverse()`：数据反转，从后往前变成从前往后。

- 合并两个列表的方法有

  1**直接相加**（`+`）

  2**解包后相加**：解包就是 `*` 加列表名（`[*list1, *list2]`）。

### 8.2 str 字符串

```
a=""
b=''#就是字符串..
```

- str 容器是**存储多个字符**的容器。
- 特点：**只能存储 str 字符数据**，有**不可变性、可迭代性(for能循环取出数据)和有序性**。可以正反向输出 `0~n`、`-1~-n`。
- 切片同list
- 方法：`find`、`count`、`upper`、`lower`、`startswith`、`endswith`、`strip`、`split`、`replace`。
- **可迭代性**的意思就是可以用 `for` 将里面的元素一个个取出来。
- 元素判断：在字符串中有多少个用 `count`，是否存在用 `in`。

### 8.3 tuple 元组
- **tuple 就是不可变版的 list**。里面的数据不可变,创建方法不同

  ```
  a=tuple()
  a=(1,2)
  a=1,#推荐
  a=(1,)#不能写成=(1)
  #嵌套写法
  a=((1,2,3),(2,3),(1,2,3,4))
  print(a)
  ```

- 写法上，`[ ]` 换成 `()`。

- 也可以不加 `()`，直接加 `,`。如果生成**单个** tuple，`()` 内的数据**要加 `,`**（`(1,)`）。

- 切片还是一样。

- 方法：
  - `index`：索引，元组中第一次出现的位置。
  - `count`：计数，元组中出现了几次。
  
- **元组的组包与解包**：
  
  ```
  a=1,2,3#组包
  b,c,d=a#解包
  *c,d=a #意思除了给d留个3.其他都给c此处c是列表
  
  特殊用发
  aa=1
  vv=2
  aa,vv=vv,aa #就可以直接交换值.原理就是元组的解包组包
  ```

### 8.4 set 集合
- **set 的特点：不可重复(自动去重复)、可修改、无序**。

  ```

  #不能 a={} 创建.这创建的是一个dict
  ```

- 方法：`add`、`remove`、`pop`、`union`、`difference`、`intersection`、`clear`。

- 在实际用法中：
  - `union` 等同于 `|`
  - `difference` 等同于 `-`
  - `intersection` 等同于 `&`

- **set 计数**实现：用推导式迭代set.用list收集.
  实现set转list

### 8.5 dict 字典
- **字典就是键值对存储的一种容器**。

- 特点：用键值对存数，**键不可重复**，**值可以修改**。

  ```
  a={}#里面数据格式"key":value,"key2":value2
  a=dict()
  ```

- **Key 不可变**，Key 的类型可以为 `int`、`float`、`str` 和 `tuple`。

- dict 若强行写重复的 K 值，后面的 K 值会**覆盖**前面的 K 值。

- 常用方法：
  - **增加和修改**都是 dict 变量名，后面 `[]` 跟 K 值 `=` Value。若字典中没有 K 值则创建，若有则修改。
  - **删除**：调用 `pop(K)` 方法删除，或 `del 字典名[K]` 删除。
  - **查询**：
    - 字典名[Key] 可以查。
    - 字典名 `.get(K)` 方法。
    - 字典名 `.keys()` 获取所有 keys。
    - 字典名 `.values()` 获取所有 values。
    - 字典名 `.items()` 获取所有 KV 值。
  - 输出遍历时：
    - `for` 可以用 K 值进行遍历，通过字典名 `[K]` 获取数据。注意要用.keys()获取所有key,才能接收key
    - 另一种是获取所有的 item，存为 `key, value` 或者 `item`，通过 `item[0]`、`item[1]` 进行输出。同样先获取.items值
  - 存为多个数，用 `()` 通过 `,` 分开是元组，所以 `.items()` 取出来的 KV 值就是元组。
  
- 用字典写购物车等，一般**商品名为 K**，其他值为 value。

## 9. 函数

> 函数：**可调用、可重复使用的代码段**。

### 9.1 定义与返回
- **定义**：

  ```
  def a(aa,ab):
  	print("1")
  	return aa,ab,1
  ```

  `def 函数名(形参)`，多的形参用 `,` 分隔，`:` 换行。里面是方法体，`return` 也用 `,` 分隔多个数据。

- 多个 `return` 值会返回元组，可用解包解开。

### 9.2 说明文档
- `#` 在函数前写概览，
  在函数体内用**三引号**写出参数以及返回值介绍。
  下次直接把鼠标放在方法名上即可查看。
- **函数嵌套**时遵循先进后出原则。

### 9.3 函数高级
- 函数里面的为**局部变量**，函数外面的为**全局变量**。
  在函数体内用 `global` 声明变量名，即可变为全局变量，一般用于改全局变量的数值。
- **参数传递** (传参时的参数) 分为**位置参数**和**关键字参数**：
  - 位置参数：默认从左往右依次对应。
  - 关键字参数：可以不按位置，随便变换位置；是 KV 值，把 `形参=值` 写上传入：`(K=value, ...)`。
  - **位置参数写在关键字参数前**。
- **可变参数用 `*args`，可选参数用 `**kwargs`**。
  - args封装为**tuple**,kwargs封装为**dict**
  - 同时存在时 `*args` 在 `**kwargs` 前。
  - 若比较简单、比较少，用 `*args`；若比较多（四五个）且容易混，就用 `**kwargs`。
  - 不定长位置参数用 `*args`（后面 arg 可以随意改）；不定长关键字参数是 `**kwargs`（kwargs 也可改）。
  - `*args` 与位置参数同时用时，**位置参数必须在前面**，
  - `*args` 与关键字参数同时用时,关键字参数随意。
  
- **默认参数**  直接在定义时传入一个参数。
  - **默认参数**必须在**位置参数**后
  - 调用时传入的参数可不写，不写就用默认的，写了就会替掉默认的。
- 参数可以为刚才学到的所有类型，叫**普通参数**；特殊参数有函数。

### 9.4 匿名函数
- 格式：`lambda 形参: 方法`，`return` 默认不用写；如果加运算它就会返回出结果。

  - **匿名函数一般用于简单的类型**。
  - 可以在匿名函数前面加一个变量接收其返回值，就能和命名函数一样了。
- **案例**：`list.sort()` 里面有个 `key` 是看怎么排序的值，那个 `key` 可以用匿名函数来返回你想要的东西；还可以加 `reverse` 反转参数进行倒排。

  ```
  students = [("张三", 18), ("李四", 16), ("王五", 20)]
  # 按年龄（元组第2项）升序排
  students.sort(key=lambda x: x[1])
  # 加上 reverse=True 倒排（年龄从大到小）
  students.sort(key=lambda x: x[1], reverse=True)
  ```

### 9.5 递归函数
- 递归函数要有**终结点**，用 `if` 判断终结点之后，再用递归调用。

  ```
  def func(n):
      # 1. 基线条件（终结点，先判断！满足就return，不再往下递归）
      if 终结条件:
          return 终止值
      
      # 2. 递归调用：参数一定要向基线靠近！（非常关键）
      return func(变化后的参数)
  ```

### 9.7 类型注解 / 类型推断
- **类型注解**：在变量后加 `:` 加类型。以后如果用到类型不一样的，它会提示。若有两个可选类型，就用 `|` 分割，表示这俩都行。

  ```
  a: int|float = 10
  ```
- **类型推断**：Python 自动帮你识别。只要是创建变量时赋了值、参与了运算、参与了推导式，都不用再类型注解。
- **函数的类型注解**，推荐加：
  
  ```
  def say(msg: str | None) -> str:
      if msg is None:
          return "空消息"
      return msg
  ```
  
  - 在形参后面 `:` 加类型。
  - 在形参的 `()` 外加箭头指向类型，这个类型代表 `return` 的格式。

## 10. 模块与包（导包）

> 导模块导包的作用：**提高代码复用性，降低上手难度，避免命名冲突**。

### 10.1 Python 模块的导包
- Python 模块就是 Python 文件。导包有 3 种主要格式：
  1. `import 模块名`（可以加 `as 别名`）
  2. `from 模块名 import 方法名`（可以加 `as 别名`）
  3. `from 模块名 import *`
- **在没有别名的情况下，`import` 后面跟的就是后续使用调用的名。**

### 10.2 包（package）
- **引入关键字**：只要有`__init__.py` 文件 的文件夹就叫**包**。
  - `__init__.py` 里面可以为空。

- **包的导入**：
  - `import 包名.模块名`：引入该模块。
  - `from 包名 import 模块名`：也是引入该模块，但不用写包名调用。
  - `from 包名 import *`：
    - 必须在 `__init__.py` 里面添加内置变量 `__all__`=[模块名(包名),模块名(包名)，否则无法引用。
  - from 包名.模块名 import 方法名
  - from 包名.模块名 import *。
    - 此时* 是看模块名里面的 `__all__`=[] 变量村的是方法,属性
- **跨文件时**，包名找不到就用绝对路径；该项目文件夹下的第一层为第一级，**不可以用 `./`**。

### 内置变量
- `__name__`：用于区分测试代码，`if __name__ == "__main__"` .本体里面就是main外面调用 里面值就是文件名
  - PyCharm 里直接输入main快捷方式回车可以快速包裹在内
- `__all__ = []`：`[]` 里面添加方法名属性。
  - [里面写的就是导入时*所含的方法属性]
